## 1. PROJECT OVERZICHT
Stay4S is een autonoom AI-platform gebouwd door Mitchell (Het Nieuwe Begin BV)
met Droid AI assistent. Het platform draait op een Raspberry Pi 5 met
Cloudflare tunnels voor externe toegang. Doel: een onafhankelijke, privacy-eerst
AI-assistent die concurreert met Big Tech diensten.

## 8. ALLE FIXES UITGEVOERD

### Cloudflare SSL (GEFIXT):
- Probleem: SSL handshake failure (mode "full")
- Fix: SSL mode veranderd naar "flexible"
- Resultaat: 14+ subdomains LIVE via HTTPS

### Cloudflared YAML (GEFIXT):
- Probleem: Verkeerde inspringing na nieuwe routes
- Fix: YAML herbouwd met correcte nesting
- Resultaat: 36 routes, cloudflared actief

### Vast.ai CDI Error (GEFIXT):
- Probleem: OCI runtime CDI device error op instance 54698962
- Fix: Instance vernietigd, nieuwe instance 54732495 gemaakt

### Vast.ai HuggingFace Blocked (GEDEELTELIJK GEFIXT):
- Probleem: Kan huggingface.co niet bereiken
- Fix: Model handmatig gedownload op PC, geupload via scp

### Vast.ai transformers import (GEFIXT):
- Probleem: v5.19.0 had GenerationMixin import issue
- Fix: Downgraded naar v4.57.6

### Vast.ai pip resolver (GEFIXT):
- Probleem: AssertionError in pip
- Fix: pip geupgrade naar v26.2.1

### AOSP HTTP 429 (GEFIXT):
- Probleem: Rate limit bij repo sync met -j64
- Fix: -j4 gebruikt

### AOSP trunk_staging (GEFIXT):
- Probleem: Missing release config
- Fix: TARGET_RELEASE=bp2a gezet

### AOSP lineage_health (GEFIXT):
- Probleem: Android.mk blocked door AOSP 16 denylist
- Fix: Directory verwijderd

### Gateway Translation (GEFIXT):
- Probleem: m2m100 "No route for that URI"
- Fix: Vervangen door Llama 3.3 70B via Cloudflare Workers AI
- Test: "Het is vandaag mooi weer" -> "The weather is nice today" PASS

### Gateway Customer Create (GEFIXT):
- Probleem: sqlite3.IntegrityError UNIQUE constraint op dubbele email
- Fix: try/except toegevoegd
- Oude gateway v1 service gestopt + uitgeschakeld
- Gateway v2 nu draaiend op poort 8130
- Test: klant5@test.nl succesvol aangemaakt (customer_id:2, tier:pro)

### UFW Firewall (GEFIXT):
- Probleem: 192.168.2.0/24 niet in UFW allow
- Fix: 8 regels toegevoegd voor poorten 8200, 8130, 11434, 8070, 8071, 8095, 8081, 8082

### GitHub Push Protection (GEFIXT):
- Probleem: Cloudflare token in commit
- Fix: Token vervangen door YOUR_CF_API_TOKEN, commit amended, gepusht
