Stay4S API Documentatie

Soevereine Nederlandse AI API - 13 endpoints, Cloudflare Llama 3.3 70B, AVG-conform, geen Big Tech afhankelijkheid

Introductie

De Stay4S API biedt Nederlandstalige AI diensten via een eenvoudige REST API. Alle verwerking gebeurt via Cloudflare Workers AI (Llama 3.3 70B) met fallback naar lokale Ollama modellen op Raspberry Pi 5.

Base URL: https://api.stay4s.com

Authenticatie

Alle endpoints (behalve /docs en /pricing) vereisen een API key via Bearer token:

Authorization: Bearer stay4s-free-demo

Vraag een API key aan via POST /customers/create.

Chat API

POST/v1/chat€ 0.001/callfree+
Nederlandstalige AI chat. Gebruikt Cloudflare Llama 3.3 70B voor optimale kwaliteit.

Request

POST /v1/chat
Authorization: Bearer stay4s-free-demo
Content-Type: application/json

{"prompt": "Wat is de hoofdstad van Nederland?"}

Response

{"endpoint": "chat", "response": "De hoofdstad van Nederland is Amsterdam.", "tier": "free"}
